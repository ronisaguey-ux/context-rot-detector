7. Verified OpenCode Configuration (Inversion-Safe buffer = model_window - T) IMPORTANT: OpenCode uses a free-token buffer below the model limit, NOT an absolute maxContextTokens key

In OpenCode V2 (https://opencode.ai/v2/docs/compaction/), compaction.buffer specifies the tokens to keep free below the model's context limit (`trigger = model_context_window - buffer`). For your 900,000-token window and recommended compaction trigger T = 215,000 tokens, set buffer = 900,000 - 215,000 = 685,000:

OpenCode V2 (opencode.jsonc — Current Standard)
{ "$schema": "https://opencode.ai/config.json", "compaction": { "auto": true, "keep": { "tokens": 15000 }, "buffer": 685000 } }
OpenCode V1 Legacy (compaction.reserved)
{ "$schema": "https://opencode.ai/config.json", "compaction": { "auto": true, "prune": true, "reserved": 685000 } }
